# Navigation learnings

Machine-specific notes for driving this desktop: window locations, coordinates,
quirks, dead ends.

## Workflows

Each workflow has its own directory under `navigation/` with the step-by-step
specifics.

- `navigation/plcnext-write-start/` - open PLCnext Engineer, open the gutenberg
  ticket project, connect to the PLC, write and start (PC)
- `navigation/engineer-rebuild/` - open the gutenberg ticket project and run the
  Rebuild All -> 0 errors -> Save gate (laptop)

## Rule

BEFORE RUNNING ANY WORKFLOW, READ ITS FILE UNDER navigation/ FIRST. Do not run a
workflow from memory or from this index alone.
